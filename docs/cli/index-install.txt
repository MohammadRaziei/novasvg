            <div class="section-label" style="margin-bottom:1rem">Option 1 — pip <span style="font-size:0.75rem;color:var(--fg2);text-transform:none;letter-spacing:0">(recommended)</span></div>
            <div class="code-wrap">
                <div class="code-label">
                    <div class="code-lang-row"><div class="code-dots"><span></span><span></span><span></span></div><span class="code-lang">bash</span></div>
                    <button class="copy-btn" onclick="copyCode(this)"><i class="fa-regular fa-copy"></i> copy</button>
                </div>
                <pre><code class="language-bash">pip install novasvg</code></pre>
            </div>
            <div class="install-note" style="margin-bottom:1.5rem">
                The Python package ships a <strong>pre-built</strong> <code>novasvg</code> binary alongside the Python extension. After install, the <code>novasvg</code> command is available directly in your shell — no compiler or CMake needed.
            </div>

            <div class="section-label" style="margin-bottom:1rem">Option 2 — build &amp; install with CMake</div>
            <div class="code-wrap">
                <div class="code-label">
                    <div class="code-lang-row"><div class="code-dots"><span></span><span></span><span></span></div><span class="code-lang">bash</span></div>
                    <button class="copy-btn" onclick="copyCode(this)"><i class="fa-regular fa-copy"></i> copy</button>
                </div>
                <pre><code class="language-bash">git clone https://github.com/MohammadRaziei/novasvg.git
cd novasvg
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)

# Install to system (adds `novasvg` to PATH)
sudo cmake --install build</code></pre>
            </div>
            <div class="install-note">
                Requires CMake 3.19+ and a C++17 compiler. Builds the binary from source — useful if you want a custom build configuration or are on a platform without a pre-built wheel.
            </div>
