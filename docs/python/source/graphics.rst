Bitmaps and Geometry
====================

Rendering produces a :class:`novasvg.Bitmap`; :class:`novasvg.Matrix`,
:class:`novasvg.Box` and :class:`novasvg.Color` are the small value types used
for transforms, bounding boxes and colors.
